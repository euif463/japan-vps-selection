## 先分清：便宜日本VPS的钱省在哪里、贵在哪里

日本VPS的价格差异基本由三件事决定，跟CPU型号关系反而没那么大。

**线路。** 东京机房回国主要有两类走法。一类是走普通国际出口，白天看着还行，晚高峰挤在国际段就现原形；另一类是三网优化直连，电信走CN2、联通走自己的骨干、移动走CMI，绕路少、丢包低，成本也高。市面上一百块以内的日本机器，绝大多数差别就在这一层。

**流量计费方式。** 同样一台1核1G，有的给你100Mbps带宽但每月只给30GB流量，有的给你5Mbps带宽但流量不限。前者适合有突发的场景，后者适合长期稳定跑小流量业务。这两种定价逻辑完全不能直接比单价。

**IP和扩容的另算项。** 很多标价是不含独立IP或只含一个普通IP的，扩容硬盘、超流量后恢复速度都要额外掏钱。这几项加起来，可能比月付本身还显眼。

## 便宜的代价：几个容易忽略的坑

日本机房便宜归便宜，有几处不看清楚会在使用中变成麻烦：

- **限速门槛。** 有限流量套餐用完流量不会断网，而是限速到1M或5M。做下载站、图床这类业务，这个数字足够让你怀疑人生，要么买流量包，要么一开始就选不限流量档。
- **流量叠加是真省钱还是心理安慰。** 流量不清零、按月叠加对波动型业务友好，但如果你是持续跑满的用法，叠加只是把超额推迟一两个月。
- **不限流量不等于能跑满。** 不限流量档位的上行只有5M到15Mbps，适合稳定的轻量业务，不适合跑带宽。想两者都要，只能上大带宽限量档。
- **IP归属。** 测评提到日本节点的IP为非原生IP，如果你的业务需要日本本地原生IP（比如某些本地化服务的风控判断），这点要提前确认，别买完才发现。
- **海外节点延迟波动。** 有测评提到海外节点偶有轻微波动，属于国际线路的正常现象，稳定性要求极高的核心业务建议留出冗余。

## 常见问题

**便宜日本VPS晚高峰会卡吗？**
取决于线路而不是价格。走三网优化直连的机器，测评数据显示全国平均延迟约72ms、联通方向约55ms，晚高峰波动相对可控；走普通国际线路的机器，白天五十几毫秒、晚上一百二以上是常见情况。买之前先确认回程线路类型。

**需要备案吗？**
海外节点不需要ICP备案，开好就能用。这也是很多人放弃国内轻量服务器、转投日本节点的主要原因。

**流量用完了会断网吗？**
不会断网，会限速。三网线路限至1M、软银线路限至5M，之后可以买流量包恢复；也可以等次月叠加的流量补充上来。

**只能装Linux吗？**
Linux和Windows都支持，也提供宝塔、1Panel、MCSManager、Docker等镜像一键安装，不熟悉环境的用户可以少折腾一步。

**支付方式有哪些？**
支付宝和微信都可以，对国内用户没有信用卡门槛。

**能退吗？**
云服务器和游戏云支持7天无理由退款，每个账号限3次；另外有过1元试用1天的入口，试错成本很低。
